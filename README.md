# tab-groups-for-github

GitHub のリポジトリを任意のグループに整理し、プロフィール／Organization の Repositories タブにグループ別タブを追加して一覧表示する Chrome 拡張機能（MV3）。

## 構成

- `manifest.json` — 拡張機能マニフェスト（MV3）
- `src/` — コンテンツスクリプト・ストレージ層・i18n・スタイル
- `popup.html` / `popup.js` / `popup.css` — グループ管理ポップアップ
- `_locales/` — 拡張名・説明の多言語（ja / en）
- `icons/` — アイコン
- `scripts/` — 配布用 zip 作成スクリプト
- `test/` — 単体テスト
- `PRIVACY.md` / `STORE_LISTING.md` — プライバシーポリシー・ストア掲載文
- `LICENSE` — MIT
