# Tab Groups for GitHub

GitHub のリポジトリを任意のグループに整理し、プロフィール／Organization の **Repositories** タブページにグループごとのタブを追加して一覧表示する Chrome 拡張機能です。

> **非公式ツール**: 本拡張は GitHub, Inc. とは提携・公認関係にありません。「GitHub」は GitHub, Inc. の商標で、本拡張の対象サービスを指す記述目的でのみ使用しています。

## 機能

- **グループは user / organization ごとに完全独立**: 開いているアカウント（プロフィール or Organization）のグループだけが表示・管理されます。同名でも別アカウントのグループは別物で、リポジトリが混在しません。
- **グループタブの注入**: リポジトリ一覧の上部に「すべて」＋（その所有者の）グループのタブを表示します。
- **グループ別一覧**: グループタブを選ぶと、そのグループに登録したリポジトリだけを一覧表示します（GitHub のページネーションをまたいで全件まとめて表示）。
- **かんたん割り当て**: 「すべて」タブの各リポジトリ行にある「＋ グループ」ボタンから、チェックボックスでグループに追加／解除できます。
- **ポップアップ管理**: ツールバーアイコンから、グループの作成・改名・色変更・並べ替え・削除、現在見ているリポジトリの追加、設定の JSON エクスポート／インポートができます。
- ライト／ダークの GitHub テーマに追従します。
- **日本語 / 英語に対応**。既定はブラウザの設定言語で自動判定（日本語以外は英語）。ポップアップから「自動 / 日本語 / English」に切り替えできます。
- **クラウド同期（任意・既定ON）**: `chrome.storage.sync` を使い、同じ Google アカウントでサインイン済みの Chrome 間で**自動同期**されます（外部サーバー・トークンは不要）。ポップアップのトグルでON/OFFを切り替えられます。

## データの保存と同期

- **同期ON（既定）**: グループとメンバーは **`chrome.storage.sync`** に保存され、Chrome のアカウント同期で他デバイスにも反映されます。sync の容量上限（1項目8KB／全体100KB）に合わせ、メタ情報とリポジトリを**バイト単位で分割（シャーディング）保存**します。
  - **件数の上限はありません**。唯一の上限は**同期容量（約90KBの安全上限）**です。
  - **使用容量の表示**: ポップアップに使用量バー（`使用容量: 12.3 KB / 90 KB (14%)`）を表示。80%でオレンジ、上限でメッセージを出して追加を停止します（容量超過で保存が黙って失敗することはありません）。
  - バイト安全策: 説明文は保存時に**120文字まで短縮**、各シャードは**約6KB**に収めます。
- **同期OFF**: `chrome.storage.local` にこの端末のみへ保存します（**容量無制限**・同期対象外）。ポップアップには「同期した場合の見込みサイズ」を表示します。
- **切り替え**: ポップアップの「クラウド同期」トグルでON/OFFできます。OFF→ON時に現データが同期容量を超えている場合は、同期を有効にできません（OFFのまま）。
- 旧バージョンのローカルデータは、更新後の初回起動時に**自動で sync へ移行**します（上限超過時は同期OFFのまま）。
- 外部サーバーへの送信は一切ありません（同期は Chrome の仕組みのみ）。

## インストール（開発者モードで読み込み）

1. Chrome で `chrome://extensions` を開く
2. 右上の「**デベロッパー モード**」を ON にする
3. 「**パッケージ化されていない拡張機能を読み込む**」をクリック
4. このフォルダ（`github-tabgroup`）を選択する

## 使い方

1. GitHub で自分（または任意のユーザー／Organization）の **Repositories** タブを開く
   例: `https://github.com/<ユーザー名>?tab=repositories`
2. 一覧の上にタブバーが表示されます。
3. 各リポジトリの「**＋ グループ**」ボタンからグループに割り当てます（その場で新規グループも作成可）。
4. グループタブをクリックすると、そのグループのリポジトリ一覧が表示されます。
5. タブバー右側の「**⚙ 管理**」リンクから、ページ内でグループの**改名・色変更・並べ替え・削除・新規作成**ができます（ツールバーのポップアップを開かなくても操作可能）。

ツールバーのアイコンを押すとポップアップが開き、グループの管理や、いま開いているリポジトリページのリポジトリをグループに追加できます。

## ファイル構成

```
manifest.json          … 拡張機能マニフェスト (MV3)
_locales/{en,ja}/      … 拡張名・説明の多言語（ストア表示用、default_locale=en）
src/i18n.js            … UI 文字列の多言語（ja / en、content / popup 共通）
src/storage.js         … 保存層（sync/local・シャーディング・同期トグル）
src/content.js         … GitHub ページへの UI 注入（プロフィール/Org アダプタ）
src/content.css        … 注入 UI のスタイル
popup.html/js/css      … グループ管理ポップアップ
icons/                 … アイコン（icon.svg がマスター、PNG は書き出し）
test/storage.test.cjs  … 保存層の単体テスト（dev）
PRIVACY.md             … プライバシーポリシー（ストア提出用）
STORE_LISTING.md       … ストア掲載文・提出メモ（dev）
LICENSE                … MIT
```

> 公開用パッケージ（zip）には拡張本体（`manifest.json` / `_locales/` / `icons/` / `popup.*` / `src/`）のみ含めれば十分です。`test/` `store-assets/` `README.md` `STORE_LISTING.md` は同梱不要（含めても害はありません）。

## データの保存と、改名・削除の扱い

- リポジトリをグループに追加した**時点のメタ情報**（名前・URL・説明・言語・公開状態・**数値リポジトリID**）を**スナップショット保存**します（保存先は同期ON/OFFに応じて sync / local。上の「データの保存と同期」参照）。グループ一覧はこの保存データだけで描画し、表示のたびに API を叩くことはありません（トークン不要・private 可・オフライン可）。
- **改名/移管への自動追従**: リポジトリは改名・移管しても変わらない**数値ID**で照合します。「すべて」タブ（＝対象ユーザーの一覧）を開いたとき、ID が一致するリポジトリの名前が変わっていれば、保存名・URL・説明などを**自動で最新に更新**します。
- **削除されたリポジトリ**: 一覧に出てこなくなるため自動追従の対象外です。グループには古い情報のまま残るので、「× 外す」で手動削除してください（将来的に GitHub API 連携で自動検知を追加可能）。

## 対応ページと制約

- **プロフィールの Repositories タブ**（`github.com/<user>?tab=repositories`）: フル対応。Star ボタン横にグループボタン、言語チップと同じ見た目のグループチップ、数値IDによる改名追従まで対応。
- **Organization の Repositories**（`github.com/orgs/<org>/repositories`）: 対応。ただし当該ページは React 製で構造が異なり安定IDも取得できないため、**説明文・言語・改名追従は非対応**（名前・URL・公開状態のみ保存）。グループ分けと一覧表示は同様に機能します。
- いずれも GitHub の HTML 構造に依存するため、GitHub 側の改修で動かなくなる可能性があります（クラッシュはせず静かに無効化）。動作しなくなった場合は目視で確認してください。

## 注意

- GitHub の HTML 構造は変わることがあります。一覧が検出できない場合は、対象が **Repositories タブ**のページか確認してください。
- 保存対象はグループとメンバー（リポジトリのメタ情報）のみで、外部送信はありません（同期は Chrome の仕組みのみ）。
